# ScholarFetch Skill

The Skill, command-line tool, and tests. For the overview and usage, see the [main README](../../docs/README.md).

From this folder:

```bash
python -m pip install .
literature-workflow doctor --mode all
```

Copy this folder into your agent's skill directory as `scholarfetch`, then invoke `$scholarfetch`. See [setup and dependencies](references/setup.md).
